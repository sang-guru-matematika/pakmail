CARA UNGGAH (GitHub web)
------------------------
1. Buka repo sang-guru-matematika/pakmail di github.com.
2. Untuk tiap berkas: masuk ke folder tujuannya, klik "Add file" → "Upload files",
   pilih berkas index.html yang sesuai, lalu Commit langsung ke main.
   Pesan commit yang disarankan: "Paket ASAS v7: Kelas 2 SD Negeri Ungaran 05 (7 paket)".
3. Tunggu 1–3 menit agar GitHub Pages menayangkan versi baru.
4. Cek: https://pakmail.web.id/paket-soal/sd/kelas-2/
   — harus menampilkan 7 kartu paket Kelas 2 dengan bank soal SD Negeri Ungaran 05.

LANGKAH WAJIB SETELAH UNGGAH — Apps Script Daftar Pembeli
---------------------------------------------------------
Gerbang nama 7 paket baru TIDAK AKAN jalan sebelum daftar mapel diperbarui:
1. Buka Apps Script Daftar Pembeli (yang sudah dipakai untuk Kelas 4).
2. Ganti blok MAPEL_LIST dengan isi berkas
   "Kode-Apps-Script-Daftar-Pembeli.gs" yang baru (sudah berisi 7 mapel Kelas 2
   + 8 mapel Kelas 4 + "semua"). PIN TIDAK BOLEH diubah.
3. Simpan, lalu Deploy → Manage deployments → pensil → New version → Deploy.
4. Uji: buka satu paket Kelas 2, daftarkan nama sendiri lewat Panel Admin,
   lalu buka paket dengan nama itu — paket harus terbuka.
