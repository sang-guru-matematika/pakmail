LANGKAH UNGGAH (GitHub web)
---------------------------
1. Ekstrak ZIP ini di komputer.
2. Buka repo sang-guru-matematika/pakmail di GitHub.
3. PENTING — hapus dulu folder lama paketnya: buka folder
   paket-soal/bahasa-indonesia-kelas-4/ → tombol "..." → Delete directory.
   (Paket sudah pindah ke paket-soal/sd/kelas-4/bahasa-indonesia/.)
4. Klik "Add file" → "Upload files" (atau tautan "uploading an existing file").
5. Buka folder hasil ekstrak, MASUK ke dalamnya, pilih SEMUA isi (Ctrl+A),
   seret ke halaman upload. Jangan seret foldernya — seret isinya.
6. Klik "Commit changes".
7. Cek: root repo menampilkan index.html, paket-soal, berita,
   perangkat-pembelajaran, CARA-UNGGAH.txt, dan CNAME.

CATATAN
-------
- Gerbang nama paket masih butuh URL /exec Apps Script (daftar pembeli per-mapel).
  Sampai URL itu dipasang, paket terkunci dengan pesan "belum dipasang".
  Panduan + kode script ada di berkas terpisah (daftar-pembeli-asas).
- Enforce HTTPS di Settings → Pages dicentang begitu kotaknya bisa dicentang.
