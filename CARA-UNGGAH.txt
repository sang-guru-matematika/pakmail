LANGKAH UNGGAH (GitHub web — sama seperti v7/v9)
-------------------------------------------------
1. Ekstrak ZIP ini di komputer.
2. Buka repo sang-guru-matematika/pakmail di GitHub.
3. Klik "Add file" → "Upload files" (atau tautan "uploading an existing file").
4. Buka folder hasil ekstrak, MASUK ke dalamnya, pilih SEMUA isi (Ctrl+A),
   seret ke halaman upload. Jangan seret foldernya — seret isinya.
5. Klik "Commit changes". (Pastikan commit benar-benar terjadi — cek daftar
   commit repo setelahnya.)
6. Tunggu 1–3 menit (GitHub Pages kadang masih menampilkan versi lama
   sesaat setelah commit — itu normal).
